# Примітка до пакета v0.2.0

Цей пакет застосовує зміни через копіювання перевірених файлів з `patch/files`, а не через `git apply`. Файл `patch/v0.2.0-stabilization.patch` залишено як довідковий diff.

Основний спосіб застосування:

```powershell
Clear-Host
Set-Location "E:\GitHub\BRAVO_SYSTEM_REPORT"
$ErrorActionPreference = "Stop"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\patch\APPLY-v0.2.0-stabilization.ps1" -Commit -Push
```
