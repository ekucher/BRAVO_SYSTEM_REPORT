# Checklist v0.2.0 Stabilization

## Перед застосуванням

- [ ] Робоча гілка створена: `bravo/v0.2.0-stabilization`.
- [ ] `git status` не містить випадкових локальних змін.
- [ ] Директорії `patch` і `review` скопійовані в корінь репозиторію.

## Після застосування

- [ ] PowerShell parser не повертає синтаксичних помилок.
- [ ] `Get-BravoSystemReport.ps1 -Profile Quick -NoPause -NoOpenFolder` виконується.
- [ ] `Get-BravoSystemReport.ps1 -Profile Full -CSV -Zip -NoPause -NoOpenFolder` створює JSON/HTML/CSV/ZIP.
- [ ] У JSON присутні `Health`, `Findings`, `CollectionErrors`.
- [ ] У HTML відображається Health Score.
- [ ] У Git немає згенерованих звітів у staged files.
- [ ] Commit message українською.
- [ ] Гілка запушена в GitHub.
