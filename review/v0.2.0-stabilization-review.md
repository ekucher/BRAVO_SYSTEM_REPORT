# Ревʼю: BRAVO SYSTEM REPORT v0.2.0 Stabilization

Дата: 2026-06-10  
Гілка: `bravo/v0.2.0-stabilization`  
Рекомендований commit message: `Стабілізовано BRAVO SYSTEM REPORT v0.2.0`

## Підсумок

Етап стабілізації можна застосовувати. Патч переводить проект зі стартового імпорту `Get-SystemAudit.ps1` у керовану версію `BRAVO SYSTEM REPORT v0.2.0` з профілями аудиту, контрольованим збором помилок, findings та базовим health score.

## Що реалізовано

- Додано профілі аудиту: `Quick`, `Full`, `Deep`, `Forensic`.
- Додано параметри:
  - `-OutputPath`;
  - `-NoOpenFolder`;
  - `-EventLogDays`.
- Виправлено конфлікти змінних іконок `$cpu`, `$disk` з об'єктами CPU/дисків.
- Додано `$ScriptStartTime` і коректне обчислення часу виконання.
- Додано `Health.Score`, `Health.Status`, `Health.Findings`.
- Додано `CollectionErrors` для контрольованої фіксації помилок збору.
- Додано `Add-AuditError` та `Add-AuditFinding`.
- Додано безпечніше отримання локальних адміністраторів через SID `S-1-5-32-544` з fallback.
- Додано розширені блоки:
  - RAM modules;
  - physical disks;
  - network adapters;
  - listening TCP ports;
  - firewall profiles;
  - automatic stopped services;
  - installed software details для `Full/Deep/Forensic`.
- Виправлено `tools/Publish-ToGitHub.ps1`: консольний вивід українською, UTF-8 з BOM, без emoji.
- Оновлено `README.md`, `CHANGELOG.md`, `docs/ROADMAP.md`.

## Обмеження review

У середовищі підготовки не було Windows PowerShell, тому виконання скрипта на Windows не проводилось. Для локальної перевірки додано PowerShell parser validation у `patch/APPLY-v0.2.0-stabilization.ps1`.

Обов'язкова локальна перевірка після застосування:

```powershell
Clear-Host
$Tokens = $null
$Errors = $null
[System.Management.Automation.Language.Parser]::ParseFile(
    "E:\GitHub\BRAVO_SYSTEM_REPORT\src\Get-BravoSystemReport.ps1",
    [ref]$Tokens,
    [ref]$Errors
) | Out-Null
$Errors | Format-List
```

Якщо `$Errors` порожній — синтаксис коректний.

## Як застосувати

Рекомендовано застосовувати на окремій гілці:

```powershell
Clear-Host
Set-Location "E:\GitHub\BRAVO_SYSTEM_REPORT"
git checkout -b bravo/v0.2.0-stabilization
```

Потім скопіювати директорії `patch` і `review` у корінь репозиторію та виконати:

```powershell
Clear-Host
Set-Location "E:\GitHub\BRAVO_SYSTEM_REPORT"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\patch\APPLY-v0.2.0-stabilization.ps1" -Commit -Push
```

Альтернатива через `git apply`:

```powershell
Clear-Host
Set-Location "E:\GitHub\BRAVO_SYSTEM_REPORT"
git apply --whitespace=nowarn ".\patch\v0.2.0-stabilization.patch"
```

Після цього:

```powershell
Clear-Host
git add README.md CHANGELOG.md docs/ROADMAP.md src/Get-BravoSystemReport.ps1 tools/Publish-ToGitHub.ps1 patch review
git commit -m "Стабілізовано BRAVO SYSTEM REPORT v0.2.0"
git push -u origin bravo/v0.2.0-stabilization
```
